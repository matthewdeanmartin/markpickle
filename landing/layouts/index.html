01 / THE EXCHANGE

Structure you can read.
Data you can use.

Markpickle maps a deliberate subset of Markdown onto ordinary Python types. Headings nest dictionaries; bullet points make lists; tables can hold records.

example.py
import markpickle
from markpickle import Config

data = {
    "Cat": {
        "Name": "Ringo",
        "Species": "Felix",
    }
}

config = Config(serialize_child_dict_as_table=False)
markdown = markpickle.dumps(data, config=config)
restored = markpickle.loads(markdown, config=config)

03 / KNOW THE BOUNDARY

Made for a shape,
not every document.

Serialization is lossy. Arbitrary Markdown is not guaranteed to become sensible Python data, and some values cannot round trip exactly. Use a Markdown parser’s AST when you need to preserve a whole document.
